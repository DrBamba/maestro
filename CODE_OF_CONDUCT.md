# Code of Conduct

Maestro follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about the work, not the person.
Harassment, insults and personal attacks are not tolerated in issues, PRs, discussions or anywhere
else in the project.

## Reporting

If someone's behaviour is a problem, report it to GitHub through
[Report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
on the comment or profile, or mention the maintainer, @DrBamba, asking for a private channel.

The maintainer may edit or remove comments, close threads, and block anyone who breaks this code.
