# Security Policy

Maestro has had no security review. The [README's Security section](./README.md#security) lists
what it does by design, such as running each repo's setup script.

## Reporting a vulnerability

Report it privately through
[GitHub's vulnerability reporting](https://github.com/DrBamba/maestro/security/advisories/new).
Please don't open a public issue.

Include what you found, how to reproduce it, and what an attacker could do with it.

## Supported versions

Only the latest `main` gets fixes.
